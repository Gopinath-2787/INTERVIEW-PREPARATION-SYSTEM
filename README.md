# Personalized Interview Preparation System

## Overview
An Agentic AI-based interview preparation system built using Streamlit and the Gemini API.

## Features
- Personalized Roadmap Generation
- AI Mock Interview
- AI Feedback & Scoring
- Memory Agent
- Progress Tracking

## Tech Stack
- Python
- Streamlit
- Gemini API
- JSON
- VS Code

## Agents
- Planner Agent
- Interview Agent
- Feedback Agent
- Memory Agent
